# YETI³ Cleaner 0.4.1-rc.4 — ПРЕДРЕЛИЗ

Нативная утилита macOS для анализа диска и очистки выбранных каталогов.
**Universal: Apple Silicon и Intel x86_64, macOS 14+.** Запуск на настоящем Intel пока не проверен.
Поддержка PowerPC, Classic Mac OS и ранних OS X остаётся в работе; этот DMG для них не подходит.
[Отдельный экспериментальный прототип Classic PowerPC](legacy/classic/README.md) собран, но не проверен запуском.
[Протокол проверок и оставшаяся совместимость](docs/verification-0.4.1-rc.4.md).

Приложение работает в строке меню **Y³**. Из неё открываются настройки, статистика,
**карта диска и каталоги**, проверка обновления. Перед очисткой требуется подтверждение.
При запуске очистки из меню сначала выполняется сканирование: окно показывает пути и размеры,
позволяет выбрать категории и отдельно включить внешние инструменты. Копии iPhone/iPad,
Homebrew, Docker, симуляторы и пользовательские каталоги не отмечены по умолчанию.
Очистка использует сохранённый список; изменившиеся после просмотра каталоги пропускаются.
В окне статистики доступны пути и причины ошибок последней очистки.

## Карта диска

Круговая диаграмма: чем больше размер — тем длиннее луч. Клик по папке открывает её
содержимое. Справа — список с размерами, поиск по имени и переход в Finder.
Можно просмотреть весь Mac, домашнюю папку или выбранный каталог/том.
Сканирование работает в фоне и ничего не удаляет. Карта дополняется во время чтения,
в центре виден индикатор, ниже — счётчик объектов. Остановка сохраняет неполные размеры.
Ошибки доступа видны. Последний снимок папки хранится в SQLite и показывается сразу
при следующем открытии; затем обновляется живыми данными. Дата и неполнота явно подписаны.
Кэш ограничен 128 последними папками; промежуточный снимок сохраняется не чаще раза в 2 секунды.
Размеры логические: APFS, снимки, клоны и закрытые системой данные могут давать расхождение
с физически занятым местом. До 180 крупнейших объектов показаны лучами, все — в списке.

## Управление каталогами

Прежние пресеты сохранены. Y³ → «Настройки» открывает единое окно: категории, читаемые
числовые поля возраста, пути исходного пресета, дополнительные папки
и исключения. Путь пресета можно выключить или заменить отдельной папкой; исходный набор
восстанавливается по подтверждению. Замена внутри исключённого пути не допускается. Исключение имеет приоритет, в том числе защищает от удаления родительской
папки. Перед запуском можно посмотреть реальный план очистки.

Документы, проекты, фотографии, системные каталоги, ключи и профили браузеров защищены.
Дополнительные папки допустимы внутри домашней папки с учётом защиты. Удаляются их
дочерние объекты, сама папка остаётся. Это не инструмент очистки произвольных системных
каталогов с правами root.

Safari: только кэши, без удаления cookies, истории, паролей и баз сессий.
Состояние вкладок и позиция просмотра видео также зависят от самого браузера/сайта.
Максимальный пресет допускает удаление локальных резервных копий iPhone/iPad при включённой
настройке. В подтверждении из меню копии требуют отдельной галочки. Docker volumes не очищаются.

В 0.4.0 исправлено применение настроек в движке, исключён двойной учёт вложенных корней,
dry-run больше не создаёт фиктивную очистку в истории. Не реализованные ранее параметры
помечены «позже» и недоступны; полный перечень — в [разборе обратной связи](docs/community-feedback.md).

## Обновление

Y³ → **Проверить обновление**. Приложение по запросу читает `downloads/latest.json` (стабильный канал) или
`downloads/latest-prerelease.json` (предрелизы, отдельный переключатель)
из публичной ветки `master` репозитория `lodos/Yeti3-Cleaner`, проверяет минимальную ОС,
скачивает DMG и сверяет SHA-256. После проверки открывает установщик.
Завершите Cleaner и карту диска, замените приложение через Finder.
Настройки и история сохранятся. Автоматической фоновой установки нет.

Анализ файлов локальный; проверка/скачивание обновления обращается к GitHub.
Содержимое и имена пользовательских файлов никуда не отправляются.

## Данные и удаление

SQLite-история: `~/Documents/Yeti3Cleaner/history.sqlite3`.
При первом обращении существующая база переносится согласованным снимком SQLite,
включая журнал WAL. Старая база сохраняется как резервная копия, новая не перезаписывается.
Настройки, правила каталогов и последний результат остаются в
`~/Library/Application Support/Yeti3-Cleaner/`.
Завершите приложение и карту диска, перенесите `.app` в Корзину. При необходимости
отдельно удалите обе указанные папки данных. Фоновые службы и автозапуск не устанавливаются.

## Сборка и проверки

Нужны Rust 1.86.0 через rustup (targets aarch64-apple-darwin и x86_64-apple-darwin),
Xcode Command Line Tools со Swift, macOS на Apple Silicon.

```sh
cargo test
xcrun swiftc -parse-as-library native/DiskScanner.swift native/ScannerTests.swift -o target/scanner-tests
./target/scanner-tests
xcrun swiftc -parse-as-library native/UpdatePolicy.swift native/UpdateTests.swift -o target/update-tests
./target/update-tests
bash scripts/package-release.sh
python3 tests/cleanup_integration.py
```

Сценарий выпуска создаёт `.app` в `dist/universal`, DMG/ZIP, SHA-256 и manifest в `downloads`.
Подпись ad-hoc, **без Developer ID и нотариализации Apple**. Не отключайте Gatekeeper целиком.

### Пробная сборка для macOS 12 Monterey

Собирайте на Mac с актуальным SDK и Rust 1.86.0; исходный `master` по-прежнему рассчитан на macOS 14+.
Для Intel запустите `./scripts/build-app.sh x86_64 12.0` и возьмите
`dist/x86_64-macos12/Yeti3-Cleaner.app`. Для Apple Silicon замените `x86_64` на `arm64`.
Обе архитектуры можно собрать командой `./scripts/build-app.sh universal 12.0` после установки
обоих Rust targets. Отдельный каталог `target/macos12` исключает повторное использование
бинарников с минимальной macOS 14. Не используйте `scripts/package-release.sh` для этой
пробной сборки: манифесты выпуска пока предназначены для macOS 14+.

Проверьте `LSMinimumSystemVersion` у основного и вложенного приложения через
`/usr/libexec/PlistBuddy -c 'Print :LSMinimumSystemVersion' .../Contents/Info.plist`,
а `minos` у всех трёх исполняемых файлов через `xcrun vtool -show-build ...`.
После переноса на Monterey проверьте запуск меню, сканирование, окно подтверждения и карту диска
до первой очистки. Совместимость с macOS 12 пока не подтверждена на устройстве.
