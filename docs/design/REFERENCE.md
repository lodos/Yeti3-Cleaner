# YETI³ Cleaner: референс Node / Connector

Владелец 2026-10-11 потребовал строго использовать дизайн Node и Connector. Источники: `yeti3-gpu-node/ios/Sources/NodeApp.swift`, `yeti3-connector/ios/Yeti3Connector/IceGlassUI.swift`, `yeti3-connector/assets/premium-ice/tokens.json`. Референсные проекты не изменялись.

Перенесены оригинальный маскот Node и статичный фон Ice Atelier Connector, палитра #07121F / #173144 / #A1DDFF, округлый крупный заголовок, панели с радиусом 22, внутренние отступы 20, внешние 24 и интервалы 22. Тонкая граница 0.8 и градиент стекла взяты из Connector. Системные SF Symbols, cyan-кнопки и стандартная доступная навигация соответствуют семейству. Настройки сгруппированы в панели с явными подписями значений на iOS и Catalyst.

Декоративных циклов, частиц, blur-анимации и собственного display timer нет. Reduce Transparency даёт непрозрачные панели и отключает фоновую текстуру. Данные и защитные подтверждения не заменяются декоративными результатами. Исходные токены сохранены рядом в `ice-atelier-tokens.json`.

Нативный Mac-клиент с картой диска и магазинный sandboxed Catalyst остаются разными вариантами. Intel-архитектура не означает поддержку старой macOS: минимум macOS 14.

В полном нативном Mac-клиенте используются те же оригинальные PNG, палитра и стеклянные карточки 22/20. Build script кладёт ресурсы и privacy manifest в основной пакет и SwiftUI helper. Заголовок iOS/Catalyst использует ScaledMetric и ViewThatFits для крупного текста и узких/меняющихся размеров окна.
