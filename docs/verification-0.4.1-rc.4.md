# Предрелиз 0.4.1-rc.4 — review PR #1

Основа: GitHub `master`, merge commit `77c2c3f`. Ветка `main` в репозитории отсутствует.

## Найдено и исправлено

- **P1: обход согласия Homebrew.** `Library/Caches/Homebrew` попадал в общую категорию кэшей и удалялся при снятом флажке Homebrew. Воспроизведено на временном HOME. Сохранённый план теперь дополнительно проверяет согласие Homebrew для самого кэша, его потомков и охватывающих каталогов.
- **P2: ложное отсутствие ошибок.** Сбой внешней команды увеличивал счётчик ошибок запуска, но не создавал запись `cleanup_entries`; окно сообщало, что ошибок нет. Ошибки запуска, код возврата и stderr теперь сохраняются вместе с командой и доступны существующему окну.

Регрессионный сценарий проверяет сохранение кэша без согласия, удаление с согласием и сохранение ошибок Docker. Все внешние команды в интеграционном тесте заменены заглушками; очистка выполняется исключительно во временном HOME.

## Проверки

- 29 Rust-тестов прошли.
- Интеграционный тест прошёл на debug и arm64 release движках.
- Swift ScannerTests, UpdateTests и CacheTests прошли.
- Swift typecheck для минимальной macOS 12 прошёл; это не проверка запуска на Monterey.

## Ограничения

Основной выпуск предназначен для macOS 14+. Запуск на физическом Intel Mac и Monterey в этой проверке не выполнялся. Подпись ad-hoc, без Developer ID и нотариализации. Экспериментальный Classic-порт не изменён.

## Готовые артефакты

Universal-сборка Rust 1.86.0 с `-D warnings` завершена для arm64 и x86_64. Все три исполняемых файла (меню, движок, карта диска) содержат обе архитектуры. DMG создан штатным `scripts/package-release.sh universal`: приложение, ссылка Applications и инструкция установки.

`hdiutil verify`, проверка ad-hoc подписи смонтированного приложения, версии основного и вложенного bundle, SHA-256 DMG/ZIP и соответствия манифеста прошли. Движок сообщает `0.4.1-rc.4`.
