# YETI³ Cleaner 1.0.0 (4): версия для проверки владельцем

11 октября 2026. Основа: GitHub master 2760a9a. Работа выполнена в отдельном клоне; незакоммиченные правки основной копии и предыдущая заявка App Store не изменены.

## Что работает в исходниках

- iPhone/iPad: локальный поиск точных дубликатов, похожих снимков, старых скриншотов, крупных видео, выбранных файлов и повторов контактов; просмотр, dry run и подтверждение удаления. Избранное, свежие снимки и последняя найденная копия защищены. JPEG-копия сохраняет оригинал.
- Три независимых профиля с 28 параметрами: категории, возраст скриншотов, защита по дате, отдельные пороги видео/файлов, длительность видео, строгость и временное окно сходства, исключения расширений, минимальный размер файлов, режим архивов, совпадение телефонов/email, неполные контакты, длина телефона, качество/размер/минимальная экономия JPEG, экономный режим и лимиты времени/объектов. Старые профили мигрируют с сохранением значений.
- Автоматический анализ при открытии: только уже разрешённые данные, выбранная частота, заряд, питание, температура и энергосбережение. Удаления без подтверждения нет.
- Отдельный BGProcessing-обзор: до 250 последних объектов и 10 секунд кооперативного бюджета, только метаданные; без хеширования, загрузки оригиналов, сети и удаления. iOS выбирает время. Это обзор для последующей ручной проверки, а не фоновая очистка системы.
- Обработка вне главного актора для глубокого анализа; потоковое хеширование, короткие паузы, проверки теплового состояния и бюджета. Отмена PhotoKit прерывает запрос ресурса. Ограничения не выдаются за полный успешный анализ. Проверки бюджета кооперативные: ожидание системного API/провайдера не имеет жёсткой гарантии длительности.
- Контекстная реклама YETI³ по умолчанию без трекинга. Бесплатный анализ доступен без аккаунта. Общий Swift SDK для iOS и нативной карты диска macOS: StoreKit, серверная проверка подписанной транзакции, восстановление, ожидающая покупка, отмена, недоступный каталог, выход из аккаунта, административные права аккаунта/устройства. Нет бесконечного сетевого polling. Истечение доступа использует один локальный таймер.
- Устройство регистрируется только отдельной кнопкой, через существующий реестр сервера. Задания GoChain, вычисления и heartbeat не запускаются. Сервер проверяет владельца устройства. Админский ключ в клиент не включён.

## Два варианта Mac

Нативный Rust + SwiftUI Cleaner для прямого распространения сохраняется, включая Intel и Apple Silicon. Он имеет доступ вне песочницы; существующий `macos/project.yml` не превращён в приложение Mac App Store.

Для магазина включён Mac Catalyst у общего SwiftUI-приложения: отдельный bundle ID `maccatalyst.ru.yeti3.cleaner.ios`, App Sandbox, выбранные пользователем файлы, Фото/Контакты и исходящие сетевые запросы. Закрытые системные кэши и глобальные shell-команды в этот вариант не входят. Проверка сборки не заменяет Validate App / App Review.

## Оплата и сервер

App Store: только StoreKit с ценой Apple, appAccountToken и серверным подтверждением перед finish. Отключение рекламы — цифровая функция; отдельная кнопка Apple Pay не является заменой IAP. Продукты `ru.yeti3.network.ads.{1,2,3,6,12,24,36}m` должны быть созданы для соответствующих приложений в App Store Connect и проверены через Sandbox/TestFlight. Реальных списаний в этой работе нет.

Клиент использует существующие API `https://license.gochain.space/api/network/v1/`: `auth/login`, `ads/catalog`, `ads/status`, `ads/apple/receipt`, `compute/devices`. Административные исключения выдаются существующим сервером через `operator/ads` с аудитом и проверкой владельца. Внешние платёжные записи применяются сервером; клиент не доверяет чеку, скриншоту, локальному переключателю или бонусному балансу.

Telegram не показан в приложении. Для @yeti3cleanerbot подготовлен отдельный webhook-сервис `services/telegram`: Stars/XTR, согласие с условиями, precheckout, successful_payment, возвраты и серверная идемпотентность. Секреты только в окружении при запуске; бот и webhook в этой работе не развёртывались. никакого скрытого от Apple платёжного интерфейса в приложении нет. В review notes необходимо честно раскрыть механизмы доступа и региональные правила. Backend и публичная политика в этой работе не развёртывались.

## Перед публикацией после проверки владельцем

- Изменить прежние ответы Data Not Collected: добровольный вход/покупка обрабатывают email, идентификаторы аккаунта/устройства и историю покупок. Privacy manifest, текст политики и метаданные обновлены в репозитории; опубликованный URL необходимо обновить одновременно с релизом.
- Настроить IAP, серверную готовность каталога и реквизиты проверки. Проверить реальную покупку/восстановление/возврат, административный аккаунт и устройство. Серверная готовность не подменяет успешную покупку.
- Проверить на реальных iPhone/iPad и Intel/Apple Silicon: ограниченные разрешения, iCloud-only, системное подтверждение/отмена, File Provider, VoiceOver и большой шрифт. Измерить Energy Log, CPU, память и нагрев на большой тестовой медиатеке. Нулевое энергопотребление или нагрев не обещаны.
- Проверить фактический запуск BGProcessing на устройстве, истечение задачи и отключение настройки. Симулятор не доказывает расписание iOS.
- Для Mac App Store: подписанный Catalyst archive, Validate App, проверка sandbox entitlements, иконки/скриншоты Mac, карточка приложения. Для прямого Mac-релиза: Developer ID + notarization универсального пакета.
- Отдельно проверить текущий статус прежней заявки Apple. Новая сборка здесь не отправлялась, настройки её автоматического релиза не менялись.

Фактические результаты локальной проверки будут записаны в `verification-2026-10-11.txt`.

## Как открыть для своей проверки

Откройте `ios/Yeti3Cleaner.xcodeproj` в Xcode, схема `Yeti3Cleaner`. Для iPhone/iPad выберите симулятор или подключённое устройство; для магазинного Mac-варианта — `My Mac (Mac Catalyst)`. Для своего устройства нужна действующая подпись Apple Developer. Сборка без подписи проверяет код, но не устанавливается на физический iPhone.

```sh
xcodebuild -project ios/Yeti3Cleaner.xcodeproj -scheme Yeti3Cleaner \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project ios/Yeti3Cleaner.xcodeproj -scheme Yeti3Cleaner \
  -destination 'generic/platform=macOS,variant=Mac Catalyst' \
  ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO CODE_SIGNING_ALLOWED=NO build
python3 -m unittest discover -s services/telegram -v
cargo test --locked
```

Для проверки удаления используйте отдельные тестовые файлы и медиатеку, заранее сохранённые в резервной копии. Для проверки интерфейса и профилей разрешения вообще не нужны. Действия регистрации устройства, входа и покупки добровольные и отдельные от анализа.
