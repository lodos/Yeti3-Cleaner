# YETI³ Cleaner — проверка владельцем, 11 октября 2026

Три приложения: полный нативный Mac 0.4.1-rc.4, sandboxed Mac Catalyst 1.0.0 (4), iPhone/iPad 1.0.0 (4). Новая сборка не отправлялась Apple, прежняя заявка не изменена. Сначала проверка владельцем.

## Возможности

Полный Mac сохраняет Rust-движок, меню Y³, интерактивную карту диска, переходы по каталогам, категории, возраст, выбранные пути, замены пресетов и исключения. Перед применением — план и подтверждение; изменившиеся пути пропускаются. Копии устройств, внешние инструменты, Docker и пользовательские каталоги требуют отдельного выбора. Docker volumes не очищаются.

Новый фоновый обзор Mac: выбранная локальная папка, до 250 объектов верхнего уровня, без рекурсии/удаления, один таймер 6/24/168 часов, питание/заряд/Low Power/температура. Работает при запущенном процессе; системный агент не устанавливается.

iPhone/iPad/Catalyst: точные дубликаты, похожие фото, старые скриншоты, крупные видео, выбранные файлы и повторы контактов. SHA-256 читается потоком. Нет загрузки оригиналов iCloud. Контакты редактируются системным редактором. JPEG-копия сохраняет оригинал, убирает EXIF/геопозицию; RAW, HDR, Live, пространственные, панорамные и отредактированные фото исключены.

Три независимых профиля, 38 параметров: категории, размеры, возраст, период съёмки, строгость/интервал сходства, архивы, разрешённые/исключённые расширения, исключённые подпапки, глубина обхода, телефоны/email, JPEG, лимиты времени/объектов, паузы и тепловой режим. Избранное и последняя доступная неизменная копия защищены всегда; серии и свежие фото — по настройкам. Изменение профиля отменяет анализ и сбрасывает результат/выбор. План живёт 15 минут; данные проверяются повторно перед применением. Логический размер не гарантирует немедленного освобождения места APFS/iCloud.

Автоматический анализ при открытии включается отдельно, работает только с уже разрешёнными категориями. BGProcessing выполняет короткий обзор метаданных; время запуска выбирает iOS. На iOS 26+ ручной анализ может продолжаться в фоне по отдельной настройке, с системным прогрессом/отменой, без очереди и фонового удаления. Отказ системы оставляет анализ на экране. Бюджеты и отмена кооперативные: системный API/провайдер может задерживать завершение.

На iOS недоступны закрытые кэши других приложений, очистка RAM или произвольной системы. Для широкой очистки Mac служит полный нативный пакет; Catalyst работает в песочнице с разрешёнными пользователем данными.

## Дизайн и Apple API

Использованы исходные ресурсы Node и Connector: маскот Node, Ice Atelier background Connector, палитра, панели 22 pt и отступы. Происхождение: docs/design/REFERENCE.md. Учитываются Reduce Transparency, крупный текст и поворот. Рекламный блок ограничен по размеру шрифта, чтобы сохранить доступ к приложению; основной контент продолжает масштабироваться.

Изучены официальные release notes iOS/iPadOS 27, macOS 27, опубликованные 27.2 beta, объявленные 27.1/iPhone Duo, BackgroundTasks/PhotoKit/StoreKit и предупреждение Apple об Intel-only приложениях на macOS 28. Изменения и границы проверки: docs/apple-compatibility-2026-10-11.md. Использован SDK 27.0; будущий runtime не объявлен проверенным. Mac Universal arm64/x86_64, минимум macOS 14; это не поддержка macOS 12.

## Реклама и оплата

Контекстная реклама включена по умолчанию, без стороннего tracking SDK. Очистка доступна без аккаунта. Сервер выдаёт исключения аккаунту/устройству, проверяет владельца и ведёт аудит. Регистрация устройства добровольная, без вычислений/heartbeat. В клиенте нет административного ключа и локальной выдачи прав.

StoreKit 2: цена Apple, appAccountToken, серверная проверка JWS до finish, восстановление, pending/cancel/retry, обновление цен при смене storefront. Центральный apple_checkout_ready пока false: нужны продукты App Store Connect и Sandbox-покупка/возврат. Apple Pay не заменяет IAP для цифрового отключения рекламы.

@yeti3cleanerbot развёрнут: отдельный systemd, TLS relay, webhook с секретом, семь сроков, согласие перед счётом, Stars/XTR, precheckout без выдачи прав, successful_payment/refund и серверная идемпотентность. Telegram не показан в клиенте; внешние права раскрыты в App Review notes. Секреты — GoChain Keychain, не Git. Основной сервис рекламы не перезапускался.

Цена по поручению владельца использует множитель 3. Измеренной себестоимости нет: временная база — существующая центральная USD-сетка, 231 Stars/USD по расчёту 3/0.013. Это плановое предположение для сверки с затратами. Сроки 1/2/3/6/12/24/36 месяцев: 2310/4158/5891/10395/18018/30492/41580 Stars. Apple показывает свои цены. Реального списания/возврата Stars ещё не было.

- Native/Catalyst Universal собраны. Локальные подписи Mac проверены; iOS development archive подписан. Это не distribution/notarization.
- Catalyst и нативная карта диска открывались на macOS 27 Apple Silicon и сверялись с референсами. После добавления native overview финальная визуальная проверка ограничена отказом CUA screen capture; компиляция и тесты overview прошли.
- Бот active/running, ready и checkout_enabled true; webhook без ошибки, очередь пуста, runtime hash совпадает с bot.py. Это проверка сервиса, не денежной транзакции.

## Перед публикацией

1. Проверка владельцем на отдельной медиатеке/файлах: limited/full/revoked permissions, iCloud/File Provider, удаление/отмена, JPEG и защищённые форматы. Личные фото/контакты автоматические тесты не удаляли.

3. Валидный Energy Log на большой медиатеке: Instruments начал запись на iPhone, но аварийно завершил финализацию. Цифр CPU/батареи/нагрева нет; нулевой расход/нагрев не обещается.
4. BGProcessing wakeup, длительный Continued Processing/expiration, iPad UI, VoiceOver, Intel hardware, runtime 27/27.1/27.2 и новый форм-фактор.
5. Distribution signing, Validate App/App Review, privacy disclosures и опубликованная политика; для прямого Mac — Developer ID/notarization. Старые StoreAssets и status build 3 сохранены как исторические.

Для проверки используется отдельный YETI³ Cleaner QA. При промежуточном responsive-прогоне iPhone также получил development-сборку production bundle: переменные окружения не переопределили Xcode build settings. Данные приложения не удалялись; финальная QA-сборка использует явные build settings. Архив production bundle — основа будущей distribution-сборки после вашей проверки. Ручной запуск — через Xcode, схема Yeti3Cleaner. Перед удалением обязательно просмотреть план.

Для отдельной QA-сборки передавайте настройки именно аргументами xcodebuild:

```sh
xcodebuild build-for-testing -project ios/Yeti3Cleaner.xcodeproj -scheme Yeti3Cleaner \
  -destination 'generic/platform=iOS' DEVELOPMENT_TEAM=YOUR_TEAM \
  CLEANER_BUNDLE_ID=ru.yeti3.cleaner.qa 'CLEANER_DISPLAY_NAME=YETI³ Cleaner QA'
```

Пакеты находятся в outputs текущего задания. SHA256SUMS-review-packages.txt фиксирует их хеши; исторические downloads не заменялись непроверенным релизом.
