# YETI³ Cleaner for iOS

Нативное приложение SwiftUI для iPhone и iPad, iOS 17+. Проект создан по архитектуре и правилам безопасности YETI³ Cleaner для macOS 0.4.1-rc.4 (`cb12f35`), изученного в `/Users/lodos/GIT/MVP/Yeti3-Cleaner`. Исходники iOS теперь включены в общий репозиторий Cleaner; существующая macOS-реализация сохранена.

## Возможности

- Три отдельных настраиваемых профиля: безопасный, средний, ручной. Ни один профиль не выбирает объекты для удаления автоматически.
- Локальный анализ разрешённой медиатеки: фото, видео, размеры доступных ресурсов, SHA-256 всех ресурсов каждого объекта, группы точных дубликатов. Live Photo сравнивается вместе с видео и дополнительными ресурсами.
- Средний режим добавляет эвристический поиск похожих снимков (dHash, близкие даты съёмки) и старых скриншотов. Эти рекомендации не являются признаком ненужности.
- Крупные видео; просмотр снимка, даты, размеров, статуса избранного. Удаление избранного запрещено.
- JPEG-копия обычного JPEG/HEIC-фото с настройкой качества и длинной стороны. До сохранения показываются изображение и размер. Оригинал всегда сохраняется; сначала расход места увеличивается. RAW, HDR, Live Photo, панорамы, составные/отредактированные ресурсы и исходники больше 100 МБ не преобразуются. Геопозиция и EXIF в копию не переносятся.
- Выбранные через системный picker файлы/папки: потоковый SHA-256, дубликаты, крупные файлы, архивы, Quick Look. Ссылки и пакеты не обходятся. Известные iCloud-объекты без локальной версии пропускаются. Сторонний File Provider может загружать данные самостоятельно при доступе; отсутствие сети в его реализации приложение гарантировать не может.
- Контакты: повторяющиеся телефоны/email и неполные записи, системный просмотр/редактирование. Совпадение не означает, что записи принадлежат одному человеку. Автоматического объединения или удаления нет.
- Раздельные разрешения при начале соответствующего анализа, поддержка ограниченной медиатеки и limited contacts на iOS 18+, переход к настройкам доступа.
- Экран со свободным местом и рекомендациями iOS. Доступа к кэшу других приложений, Safari и системным данным нет.

## Безопасность

Сканирование не изменяет личные данные. Перед удалением — отдельный экран с перечнем, предупреждением об iCloud/необратимости и обязательным подтверждением. PhotoKit затем применяет системное подтверждение. Содержимое повторно проверяется перед удалением; в каждой найденной группе точных дубликатов сохраняется хотя бы один доступный неизменённый объект. Файловые операции координируются с File Provider. Внешнее изменение сохраняемого дубликата после проверки полностью исключить невозможно; нужна резервная копия важных данных.

Размеры — логические суммы ресурсов, не обещание физически освобождённых байтов. Удалённые фото остаются в «Недавно удалённых»; Cleaner не очищает этот альбом. У файлов возможность восстановления зависит от провайдера. Ошибки и пропуски показываются; после изменения результаты требуют нового анализа.

## Архитектура и связь с macOS

macOS использует Rust для CLI, правил, истории и AppKit-меню; SwiftUI + Foundation для карты диска и настроек. Переиспользованы правила scan → review → confirm → revalidate, раздельные профили, защита важных объектов и цветовая система Glass + Ice (тёмно-синий/голубой). Код обхода домашнего каталога, shell-процессы, macOS-пресеты и загрузчик обновлений не подходят iOS и не включены.

- `Core/CleanerPolicy.swift`: профили, правила выбора и защиты, проверяемые отдельно.
- `Services/PhotoService.swift`: PhotoKit, потоковый SHA-256, локальный визуальный анализ, JPEG-копия.
- `Services/FileService.swift`: security-scoped URLs, координация, хеширование и повторная проверка.
- `Services/ContactService.swift`: Contacts, только анализ.
- `App/CleanerModel.swift`: состояние UI, задачи и отмена; сервисы работают вне главного актора.
- `Views/`: SwiftUI, PhotosUI, ContactsUI, Quick Look.
- `Resources/PrivacyInfo.xcprivacy`: причины использования разрешённых API.

Нет сторонних библиотек, сервера, рекламы, аналитики, лицензирования или сбора пользовательского контента. Настройки хранятся в UserDefaults, результаты и пути — в памяти. iOS может самостоятельно сохранять снимок интерфейса для переключателя приложений. Облачная синхронизация Apple и File Provider управляется пользователем вне Cleaner.

## Сборка

Откройте `Yeti3Cleaner.xcodeproj`, выберите схему `Yeti3Cleaner`, симулятор iPhone/iPad и Run. Полный Xcode-проект и shared scheme включены; XcodeGen для открытия не требуется. Для воспроизведения проекта после изменения `project.yml`: `xcodegen generate`.

```sh
xcodebuild -project Yeti3Cleaner.xcodeproj -scheme Yeti3Cleaner \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project Yeti3Cleaner.xcodeproj -scheme Yeti3Cleaner \
  -destination 'platform=iOS Simulator,name=iPhone 15 Pro,OS=17.5' test
```

При нескольких одноимённых симуляторах используйте конкретный `id` из `xcrun simctl list devices available`.

Публикация: `Release/TESTFLIGHT.md`. Метаданные: `Release/AppStoreMetadata.json`. Политика для размещения на сайте: `Release/privacy-policy.html`. Проверки и фактические ограничения: `Release/VERIFICATION.md`.
